Patterns

Cross-module flow templates for booking, checkout, and moderation.

Progressive Checkout Pattern

  1. Select asset/service
  2. Verify identity and trust checks
  3. Secure payment (deposit-first or full)
  4. Track legal/fulfillment status
  5. Confirm settlement + notifications

Dispute Resolution Pattern

  1. Incident report with evidence
  2. Attendance / milestone reconciliation
  3. Questionnaire arbitration
  4. Admin ruling + payout split
