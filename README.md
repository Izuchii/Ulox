# Ulox Mobile App UI System

A mobile-first React Native UI system prototype for **Ulox**, a real estate super-platform spanning:

- Land & Property Listings (Rent, Buy, HomeBuy Assist)
- Reels
- DwellHub
- LabourHub
- Admin Console

## What is included

- Design system pages: **Foundations, Components, Patterns, App Screens, Admin**
- Navigation hierarchy with requested top-tabs and sub-tabs
- Complete frame catalog for marketplace, checkout, booking, moderation, and admin workflows
- Reusable component inventory (buttons, inputs, cards, navigation, filters, badges, modals, tables, notifications)
- Responsive listing grid logic with desktop 4-column behavior
- User auth and profile system frames (login, signup, phone verification, KYC states, saved entities, settings)

## Run

```bash
npm install
npm run start
```

Use Expo device/emulator/web preview to inspect the frame system.
