# Ulox UI System — App Screens (Mobile First)

## Home Screen Frames
1. **Unified Home**
   - Top tabs, location selector, universal search.
   - Personalized quick actions: Rent, Buy, Reels, DwellHub, Labour jobs.
2. **Discovery Hub Feed**
   - Mixed recommendations from all modules.

## Land & Property Listings Frames
### Rent > Properties
1. Property listing grid/feed.
2. Search + filter interface (map/list toggle).
3. Property detail page.
4. Schedule property tour (calendar + slot picker).
5. Rental checkout flow.

### Rent > Roommates
1. Roommate listing feed.
2. Roommate detail page.
3. Roommate profile page.
4. Contact reveal interface.

### Buy
1. Property buy listing feed/grid.
2. Property detail (buy-specific financials).
3. Property purchase flow.
4. Title verification display.
5. Deposit-first purchase flow.
6. Conveyancing progress tracker.
7. Registry lodgement status.
8. Settlement confirmation.

### HomeBuy Assist
1. Eligibility onboarding.
2. Assistance plan recommendation.
3. Matched properties with assist badge.
4. Assisted checkout and approval status.

## Reels Module Frames
1. Vertical reels feed.
2. Reel viewer (full-screen).
3. Reel engagement actions (like, comment, share, save).
4. Reels with contextual CTAs (book tour, view property, buy product, hire worker).

## DwellHub Frames
### DwellHub Goods
1. Product discovery feed.
2. Product card variants.
3. Product detail page.
4. Cart.
5. Checkout.
6. Delivery OTP verification.

### DwellHub Services
1. Service discovery.
2. Service provider profile.
3. Booking interface.
4. Negotiated offer interface.
5. Booking confirmation.
6. Service completion confirmation.

## LabourHub Frames
1. Available jobs feed.
2. Job detail page.
3. Job funding confirmation.
4. Worker attendance interface.
5. Dispute reporting interface.
6. Questionnaire arbitration interface.
7. Settlement result screen.

### Authentication

## Responsive Behavior
- Mobile: single-column feed/cards.
- Tablet: two-column discovery grids.
- Desktop marketplace: 4-column listing grid for properties/products.
