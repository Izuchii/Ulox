# Ulox UI System — Patterns

## Navigation Pattern
- **Primary top tabs:**
  1. Land & Property Listings
  2. Reels
  3. DwellHub
  4. LabourHub
- **Land & Property sub-tabs:** Rent, Buy, HomeBuy Assist.
- **Rent sub-tabs:** Properties, Roommates.

## Discovery Feed Pattern
- Header with location + search.
- Sticky filters row.
- Card feed/grid content.
- Empty state + recommendation block.

## Detail Page Pattern
- Media carousel.
- Trust strip (verified/KYC/title status).
- Core attributes.
- Description.
- Related entities.
- Primary CTA bar fixed at bottom.

## Checkout / Booking Pattern
- Stepper (1/4, 2/4…)
- Summary card.
- Payment method.
- Verification gate (OTP/KYC/title).
- Confirmation state with reference ID.

## Moderation Pattern (Admin)
- Queue table + severity filters.
- Split view: item details + decision panel.
- Action logging and audit trail.

## Negotiation Pattern
- Offer timeline chat UI.
- Counter-offer chips.
- Expiry countdown.
- Accept/Decline with confirmation.

## Progress Tracking Pattern
- Milestone tracker with states:
  - Not started
  - In progress
  - Blocked
  - Completed
- Used in conveyancing, registry lodgement, and settlement.

## Trust & Verification Pattern
- Every high-risk action requires trust block:
  - ID/KYC status
  - Title verification outcome
  - Escrow/deposit protection note
  - Regulatory disclaimer
