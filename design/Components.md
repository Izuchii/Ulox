# Ulox UI System — Components

## Buttons
1. **Primary Button** (48h)
   - Filled blue, white text.
   - States: default, pressed, disabled, loading.
2. **Secondary Button**
   - Neutral stroke, dark text.
3. **Ghost Button**
   - Transparent bg, blue text.
4. **Destructive Button**
   - Red fill for irreversible actions.
5. **FAB CTA**
   - Circular primary, plus/action icon.

## Inputs
- Text input (label, helper, error).
- Search field with chip filters.
- Phone input with country selector.
- OTP 6-digit grouped inputs.
- Date/time picker trigger field.
- Price range dual input.
- Multi-select bottom-sheet selector.

## Cards
- **Property Card:** image, price, location, bedroom/bath, badges, CTA.
- **Roommate Card:** avatar, budget, preferred areas, compatibility score.
- **Reel Card:** cover thumbnail, duration, engagement counter, contextual CTA.
- **Product Card:** image, brand, price, rating, stock state.
- **Service Card:** category, provider badge, starting price, response time.
- **Job Card:** role, pay, location, urgency state.

## Navigation
- Top tab bar (4 core modules).
- Nested segment control (Rent / Buy / HomeBuy Assist).
- Sub-segment control (Properties / Roommates).
- Bottom nav (Home, Saved, Inbox, Profile) optional global shell.
- Sticky action footer for checkout/booking flows.

## Filters
- Horizontal pill filters.
- Advanced filter modal with accordion sections.
- Sort bottom sheet.
- Saved filter preset chip.

## Badges
- Verification badge.
- KYC state badge.
- Sponsored label.
- New listing/product tag.
- Urgent job badge.

## Modals & Sheets
- Confirmation modal.
- Negotiated offer sheet.
- Contact reveal modal.
- Report dispute modal.
- Multi-step checklist sheet.

## Tables (Admin)
- Listing moderation table.
- Dispute queue table.
- Transaction ledger table.
- User management table.
- CMS content table.

## Notifications
- Toasts: success, warning, error, info.
- Inline banners.
- In-app inbox notification cards.
- Transaction milestone notifications.
